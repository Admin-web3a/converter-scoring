# Скоринг гипотез конвертеров

Страница для командной приоритизации гипотез конвертеров Web3 Academy. Пятеро участников
проставляют оценки независимо и вслепую, результаты собираются в Google Таблицу, страница строит
среднее и итоговое ранжирование.

Публикуется через GitHub Pages из папки `docs/`.

## Что внутри

- `docs/index.html` — вся страница одним самодостаточным файлом, без сборки и зависимостей
- `apps-script/Code.gs` — приёмник данных для Google Apps Script

## Как работает сохранение оценок

GitHub Pages отдаёт только статику, поэтому хранилищем выступает Google Таблица, а посредником —
веб-приложение Apps Script. Страница отправляет туда оценки методом POST и читает все накопленные
методом GET.

В таблице лежит по одной строке на пару «человек и гипотеза», всего до 40 строк при пятерых
участниках. Повторная отправка удаляет прежние строки того же человека, поэтому дублей не
накапливается и в таблице всегда актуальная версия.

| Отправлено | Кто | ID гипотезы | Гипотеза | Impact | Confidence | Effort | TimeToSignal | Комментарий |
|---|---|---|---|---|---|---|---|---|

## Настройка за пять шагов

1. Создайте новую Google Таблицу.
2. В ней откройте «Расширения» → «Apps Script», удалите содержимое `Code.gs` и вставьте туда код из
   `apps-script/Code.gs`.
3. Нажмите «Начать развёртывание» → «Новое развёртывание», тип «Веб-приложение», запуск от своего
   имени, доступ «Все». Подтвердите запрос разрешений.
4. Скопируйте выданный адрес — он оканчивается на `/exec`.
5. В `docs/index.html` найдите строку `var API_URL = "";` и вставьте адрес внутрь кавычек. Закоммитьте
   и запушьте.

Лист `scores` и строка заголовков создаются автоматически при первом обращении.

## Проверка без правки файла

Адрес приёмника можно передать параметром в ссылке, не трогая код:

```
https://<аккаунт>.github.io/converter-scoring/?api=https://script.google.com/macros/s/<id>/exec
```

Удобно, чтобы проверить связку до публикации.

## Если хранилище не подключать

Страница работает и без Apps Script. Оценки сохраняются в браузере участника, а кнопка «Скопировать
результат» кладёт их в буфер обмена в виде JSON — его можно прислать в Telegram и свести вручную.
В этом режиме вкладка «Сводка команды» остаётся пустой.

## Особенности поведения

Оценки скорятся вслепую: вкладка «Сводка команды» открывается только после того, как участник
отправил свои значения. Черновик автоматически сохраняется в браузере, так что форму на 32 числа
можно заполнить в несколько заходов.

В сводке отдельно подсвечиваются гипотезы, где команда расходится всерьёз: разница по Impact от двух
баллов или разница по Effort вдвое и больше. Такие строки выносятся на обсуждение, а не усредняются —
среднее спрятало бы разногласие.
